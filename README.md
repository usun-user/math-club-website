# math-club-website
Interactive math problem-solving platform with progressive hints and automatic answer checking. Designed for school Math Club.

Project Goals:
- Provide math problems organized by topic and difficulty
- Offer progressive hints written by Math Club execs
- Automatically or manually check student answers
- Allows students to create accounts and track their progress
- Encourage independent math thinking

Technology Stack:
- Frontend: React, TypeScript, Vite ?
- Development: Node.js
- Hosting: Cloudflare Pages (free)
- Backend: Supabase Edge Functions
- Database: Supabase PostgreSQL
- Authentication: Supabase Auth
- Math Rendering: KaTeX or LaTeX

Project Status:
Initial development: setting up the repository and project structure.
